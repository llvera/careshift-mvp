# CareShift 网页 MVP

单个小規模多機能型居宅介護事业所的月度排班原型。使用 HTML、CSS 和 JavaScript，无需安装前端依赖。

## 本地运行

下载仓库，在目录中运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173/ 。

## 使用

1. 在“员工与兼职时间”编辑示例四位数工号、姓名、雇佣类型、生日和兼职可出勤星期及起止时间。
2. 点击排班单元格设置希望休、有休、生日假、具体班次或锁定。
3. 点击自动排班，再查看冲突检查并调整。
4. 支持月份切换、CSV导出、JSON备份与恢复。数据保存在本机浏览器，仓库中只有示例人员，不包含真实排班照片或浏览器内数据。

## 当前规则

- 示例人员：9名正社员、7名兼职；管理者仅早班。
- 正社员2月公休9天，其余月份10天；最多连勤5天，倾向工作2～3天后休息。
- 早班组合至少3人，允许2早＋1中，其中2人在8点前到岗；17～19点至少3人在岗。
- 兼职排班起止时长3～9小时，按允许星期和时间安排。在岗满8小时扣除1小时休息：11～20点计8小时实际工作。
- 夜勤仅正社员承担，每晚1人，两夜两休。上一组第二夜到下一组首夜至少7天，无明け。夜勤暂定21～次日06点，含1小时休息，可修改。
- 每名正社员每自然年1天生日假。生日当月自动安排当天；更改生日会迁移未锁定的自动生日假。已在其他日期使用年度额度时不重复增加，锁定冲突会提示。2月29日非闰年需手动选择休假日。
- 有休及生日假额外增加休息，不抵扣公休，自动排班保留。
- “排班规则”可登记员工相性，不契合可选择尽量不同日或同日分早晚班。作为优化偏好处理，人员配置、休假等优先；未满足会提醒。

## 原型边界

自动排班使用启发式候选搜索，不保证找到最优或完全可行排班。白班暂定早07～16、中09～18、晚11～20。尚未分配具体休息、访问、入浴任务，人数覆盖按在岗时间统计。尚未检查所在地法定配置、设置账号权限或实现多人云端协作。跨月信息需手工登记；生日假年度额度按本机已保存月份统计。每月数据备份文件仅包含当前月及相关设置，其他月需分别备份。

非管理者正社员每月早班目标至少4次、晚班至少6次。自动排班优先补足；人员覆盖、休假或锁定冲突时可安排中班，未达次数显示偏好提醒。月表和CSV分别显示早、中、晚次数。验证：`node check-shift-targets.cjs`。

每日早班组合上限4人、下限3人（早班、中班和开始时间早于09点的兼职合计）。自动排班避免超过上限，手动及锁定排班超过4人会显示冲突。验证：`node check-early-cap.cjs`。

夜勤规则更新（2026-10-13）：普通正社员每组两夜勤、后两休，下一组首夜距上一组第二夜至少10天。工号1009例外：每月恰好2次单次夜勤，不连续，两次开始日期至少间隔10天，每次后两休。锁定或休假导致无法满足时保留冲突提示。验证：`node check-night-policy.cjs`。

员工页支持添加、编辑、删除任意员工。删除需确认，会清理所有已保存月份中该员工的相关数据。可恢复最近一次删除前的完整快照；恢复会覆盖删除后所做的修改。验证：`node check-staff-removal.cjs`。

司机岗位：员工页添加或编辑员工，岗位选“司机”。在月表中由管理员手动选择司机班次和起止时间。司机班次自动排班保留，不参与现场覆盖、早晚人数、夜勤、公休及连勤等工作人员规则计算。验证：`node check-driver.cjs`。

中文／日本語：页面右上角选择语言，语言偏好保存在本机浏览器。界面、弹窗、规则提示及CSV标题随语言切换，员工姓名和工号保留原文，排班数据内部值保持不变。运行时请同时保留 `i18n.js`。验证：`node check-language.cjs`。
